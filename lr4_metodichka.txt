Объектно-ориентированное программирование с использованием 
функций и классов стандартной библиотеки языка С++ 
Тема: Освоение механизма управления исключениями, а также функций и 
шаблонов классов стандартной библиотеки языка С++. 
Цель работы 
Целью лабораторной работы  является освоение и практическое 
применение программных  конструкций механизма управления исключениями 
языка С++, а также функций и шаблонов классов стандартной библиотеки языка 
С++. 
Порядок выполнения работы 
Написать программу (консольное приложение), реализующую указанный 
вариант задания . При объектно-ориентированном проектировании классов 
объектов предметной области программы необходимо максимально использовать 
классовые типы, шаблоны классов и функции стандартной библиотеки языка С++.  
При разработке программы необходимо: 
• применить механизм динамического создания анонимных объектов с 
использованием операторов new и delete; 
• включить в программу блоки контроля возможных исключительных 
ситуаций, 
• применить механизм исключений для контроля ошибок ввода данных. 
Форма отчётности: 
Для отчёта по лабораторной работе требуется: 
• продемонстрировать преподавателю работу программы на компьютере; 
• представить преподавателю письменный отчет в установленной форме 
с описанием модели предметной области (перечень сущностей и связей 
с указанием их имён, свойств и методов управления), и 
соответствующих классов. 
Форма отчетности 
Для отчета по лабораторной работе требуется представить результат 
выполнения программы на компьютере и отчёт в установленной форме, 
включающий в себя: 
• Титульный лист (см. Приложение). 
• Текст задания. 
• Описание информационной модели предметной области программы 
(перечень выделенных сущностей с указанием их имён, свойств и 
методов управления).

СПИСОК ЗАДАНИЙ 
ЗАДАНИЕ № 1 
Написать программу управления информацией, состоящей из трех списков: 
1) Динамически формируемый список записей спецификаций датчиков формата: 
{<шифр_датчика>; <название_датчика>;}. 
2) Динамически формируемый список записей спецификаций подсистем: 
{<шифр_подсистемы; <название_подсистемы>}. 
3) Динамически формируемый список индексных записей формата: 
{<индекс_записи_в_списке_датчиков>; 
<индекс_записи_в_списке_подсистем>}. 
Список индексных записей  фиксирует принадлежность датчиков подсистемам. Датчик 
может быть задействован только в одной подсистеме или нигде. 
Индекс записи – это порядковый номер записи в соответствующем списке. 
Шифры датчиков – трёхзначные целые числа. 
Названия датчиков – символьные строки произвольной длины. 
Шифры подсистем - двузначные целые числа. 
Названия подсистем – символьные строки произвольной длины. 
Программа должна обеспечивать выполнение следующих функций: 
1. Добавление нового датчика (добавление записи в конец списка датчиков). 
2. Добавление новой подсистемы (добавление записи в конец списка подсистем). 
3. Включение датчика в подсистему. 
4. Исключение датчика из подсистемы. 
5. Удаление подсистемы (удаление записи из списка подсистем). 
6. Удаление записей неиспользуемых датчиков из списка датчиков. 
7. Вывод на экран по заданному шифру подсистемы списка входящих в неё датчиков.

{<Фамилия И.О> - символьная строка; 
 <Табельный номер сотрудника> - четырёхзначное целое число};

3. Прием сотрудника на вакантную должность. 
4. Увольнение сотрудника.
